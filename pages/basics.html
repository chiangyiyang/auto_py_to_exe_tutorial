01. 從虛擬環境開始

這個章節會讓你在乾淨環境完成第一個可執行檔，後續所有章節都建立在這個流程上。

Step 1: 建立專案與 venv

mkdir demo_pack
cd demo_pack
    python -m venv env
    env\Scripts\activate

Step 2: 安裝工具與相依套件

python -m pip install --upgrade pip
pip install auto-py-to-exe pyinstaller
pip freeze > requirements.txt

Step 3: 建立最小範例

# hello.py
print("hello exe")

Step 4A: 使用 auto-py-to-exe（GUI）

auto-py-to-exe

在 GUI 中選擇 Script、Onefile、Console Based，按下 Convert .py to .exe。

Step 4B: 對照等價 pyinstaller 指令

pyinstaller --onefile --console --name hello_app hello.py

Step 5: 驗證輸出

若成功，輸出在 dist 資料夾。把 exe 複製到其他目錄執行，確認不依賴本機 Python。

常見錯誤：忘記啟用 venv、在系統 Python 安裝套件、或同時混用多個 Python 版本。
