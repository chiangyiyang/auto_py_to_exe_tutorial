範例：CLI 命令列工具

此範例示範最基礎的命令列應用打包方式，適合做第一個 onefile 實驗。

範例位置

assets/examples/cli/main.py

執行測試

python main.py --name Copilot

pyinstaller 指令

pyinstaller --onefile --console --name cli_sample main.py

auto-py-to-exe 設定

  • 腳本位置（Script Location）：main.py
  • 單一檔案（Onefile）
  • 主控台模式（Console Based）
  • 輸出名稱（Name）：cli_sample
