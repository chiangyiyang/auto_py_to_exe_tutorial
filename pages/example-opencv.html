重型套件 參數

範例：OpenCV 影像處理

此範例會輸出一張圖片，重點在 cv2 的收集方式。

範例位置

assets/examples/opencv/main.py

安裝與執行

pip install -r requirements.txt
python main.py

pyinstaller 指令

pyinstaller --onedir --console --name opencv_sample --hidden-import cv2 --collect-all cv2 main.py

auto-py-to-exe 設定

  • 腳本位置（Script Location）：main.py
  • 資料夾模式（One Directory）
  • 主控台模式（Console Based）
  • 進階參數（Advanced）：--hidden-import cv2、--collect-all cv2
