auto-py-to-exe 教學
重型套件 參數

範例：Flask 網頁服務

此範例重點在 templates 與 static 目錄的打包。

範例位置

assets/examples/web/app.py

安裝與執行

pip install -r requirements.txt
python app.py
# 開啟 http://127.0.0.1:5000

pyinstaller 指令

pyinstaller --onedir --console --name flask_sample --add-data "templates;templates" --add-data "static;static" app.py

auto-py-to-exe 設定

  • 腳本位置（Script Location）：app.py
  • 資料夾模式（One Directory）
  • 主控台模式（Console Based）
  • 附加檔案（Additional Files）：templates -> templates、static -> static
