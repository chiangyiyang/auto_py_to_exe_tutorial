範例：YOLO 模型載入

此範例重點在模型檔 yolo11n.pt 的打包與執行期路徑解析。

範例位置

assets/examples/yolo/main.py

安裝與準備

pip install -r requirements.txt
# 將 yolo11n.pt 放入 model/ 目錄
python main.py

pyinstaller 指令

pyinstaller --onedir --console --name yolo_sample --collect-all ultralytics --collect-all torch --add-data "model;yolo_model" main.py

auto-py-to-exe 設定

  • 腳本位置（Script Location）：main.py
  • 資料夾模式（One Directory）
  • 主控台模式（Console Based）
  • 附加檔案（Additional Files）：model -> yolo_model
  • 進階參數（Advanced）：--collect-all ultralytics、--collect-all torch
