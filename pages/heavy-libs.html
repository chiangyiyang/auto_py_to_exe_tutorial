05. 常見套件與附屬資料檔案打包重點

OpenCV

  • 常見問題是 cv2 子模組或 DLL 未被正確收集。
  • 先試 hidden-import，不夠再用 collect-all。
pyinstaller --onefile --hidden-import cv2 --collect-all cv2 app_cv.py

YOLO (ultralytics + torch)

  • 模型檔例如 yolo11n.pt 需用 add-data 帶入。
  • 模型路徑請以執行期路徑解析，不要寫死開發路徑。
pyinstaller --onedir --collect-all ultralytics --collect-all torch --add-data "model\yolo11n.pt;model" app_yolo.py

查看 YOLO 範例頁

FastAPI / Flask

  • 模板與靜態檔需要 add-data。
  • EXE 適合內部 Demo，正式部署仍建議容器或服務流程。
pyinstaller --onedir --add-data "templates;templates" --add-data "static;static" app_web.py

附屬資料檔案讀取範例

from pathlib import Path
import sys

def resource_path(rel_path: str) -> Path:
    if hasattr(sys, "_MEIPASS"):
        return Path(sys._MEIPASS) / rel_path
    return Path(__file__).resolve().parent / rel_path

model_path = resource_path("model/yolo11n.pt")
關鍵：重型套件先用 onedir 驗證，再決定是否轉 onefile，以免除錯成本過高。
