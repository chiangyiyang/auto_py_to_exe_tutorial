02. 打包型態 + 範例

型態 參數 優點 缺點 適用情境
One File --onefile 單一檔案方便分發 首次啟動較慢、較易誤判 給非技術使用者快速交付
One Directory --onedir 啟動快、除錯容易 檔案多，不利傳遞 內部工具、頻繁更新

範例 1: CLI 快速交付

pyinstaller --onefile --console --name text_tool cli_tool.py

範例 2: GUI 桌面工具

pyinstaller --onedir --windowed --icon app.ico --name desk_tool gui_app.py

範例 3: 帶設定檔與模板

pyinstaller --onedir --add-data "config;config" --add-data "templates;templates" app.py
策略建議：開發期優先 onedir，發佈期依需求切 onefile；不要一開始就用最複雜參數。
